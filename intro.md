# Gaza Evacuations

This interactive analysis visualizes the accuracy of evacuation orders issued by the Israeli Defense Forces (IDF) across Gaza.

## What's Inside

- **Displacements**: Cleaning and translating the evacuation order tweets we collected from the IDF's official Arabic channel, extracting location names.
- **Political Violence Events**: Filtering ACLED data to isolate relevant attacks by the IDF in Gaza post-7 October 2023.
- **Mapping Block Numbers**: Converting the list of blocks mentioned in the evacuation orders to geographical polygons using official IDF block boundaries.
- **Visuals**: Interactive maps displaying evacuation zones and nearby IDF attacks on the following days.
